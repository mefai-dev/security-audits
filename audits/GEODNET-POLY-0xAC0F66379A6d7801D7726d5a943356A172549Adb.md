## Why This Report Exists

GEODNET markets itself as a blockchain based, decentralized physical infrastructure network (DePIN) for centimeter grade RTK GPS positioning, where operators "mine" GEOD by running satellite base stations. Prospective miners and token buyers are asked to trust two load bearing claims: that location data is genuinely validated ("proof of location"), and that GEOD rewards flow from a decentralized on chain mechanism. This report tests those claims against the ACTUAL public source that exists and against live Polygon state, and separates what the blockchain enforces from what a central GEODNET backend decides.

## Method

1. Live token verification over public Polygon RPC (polygon-bor-rpc.publicnode.com and polygon.drpc.org agreed on every value). Called name, symbol, decimals, totalSupply, cap, paused, MINTER_ROLE, and enumerated AccessControlEnumerable role members. Read EIP-1967 proxy slots. Pulled bytecode.
2. Source verification cross checked via Sourcify v2 (Polygon chainId 137).
3. On chain inspection of the documented mining distribution wallet: balance, contract-or-EOA check (eth_getCode), and outgoing transaction count (nonce).
4. Read the public GitHub org repo by repo to establish what is open versus closed.
5. Read the official documentation (docs.geodnet.com) including the consolidated llms-full export, the tokenomics page, the reward metrics page, and the mining basics page, to capture the projects own description of how rewards and validation work.
6. Labeled each claim CONFIRMED IN CODE / OVERSTATED / FALSE with the repo/file or the on chain fact. Where the determining code is not public, the finding is reported as closed or unverifiable and the unseen claim is NOT credited.

## The Foundation: A Clean, Ossified Token Sitting On Top Of An Off Chain Machine

The GEOD token itself is one of the cleaner DePIN tokens on chain. It is a Sourcify verified standard OpenZeppelin ERC20 composed of Capped, Burnable, Pausable, Permit (the `permit` selector `0xd505accf` is present in the runtime) and AccessControlEnumerable. The entire 1,000,000,000 supply is already minted (totalSupply equals cap), and every privileged role has zero members: no address can mint, none can pause, and none can grant roles. The implementation is not behind a proxy. In plain terms, the token is effectively frozen: supply can only stay flat or fall (via burn), and there is no admin key, mint key, or pause key to abuse. For a token contract this is close to best case.

The important consequence is architectural. Because there is no minter and the cap is already reached, GEOD rewards CANNOT be created on chain. Everything the project calls "mining" happens off chain: a GEODNET backend measures GNSS data quality and then moves already existing tokens out of a treasury style wallet. The blockchain is the payment rail and the ledger; it is not the validator and not the emitter. The rest of this report follows that dividing line.

## Claim 1: GEODNET is a decentralized network with "proof of location" from satellite data

CLAIM: The docs describe GEODNET as "a Web3.0 blockchain-based highly-reliable RTK (Real-Time Kinematics) Network using #DePIN (Decentralized Physical Infrastructure Network) principles," rewarding operators for providing verified reference GNSS data.

REALITY: A genuine data quality mechanism exists, but it is an off chain backend heuristic, not a cryptographic or on chain proof of location. The docs state plainly: "In the backend system, GEODNET monitors the GNSS signal quality and issue GEOD tokens based on the GNSS signal quality." The reward metrics page describes counting satellites with SNR at or above 32, effective online time (linear since 2022), neighbor distance penalties (since 2023), and multipath and band classification (approved in GIP6, April 2025). It explicitly says signals below the threshold "will not be used in GEODNET backend algorithm" and that values are "displayed on GEODNET console map." There is NO documented anti spoofing mechanism, no cryptographic attestation, and no on chain verification contract.

EVIDENCE: docs.geodnet.com/geod-mining/token-reward-metrics; docs.geodnet.com consolidated export ("In the backend system, GEODNET monitors the GNSS signal quality and issue GEOD tokens"); on chain, there is no validation or oracle contract in the token and no verifier address in scope; the reward computation code is not present in github.com/geodnet.

IMPACT: The data-quality reward is real and non trivial, so the network is not vacuous. But the "proof of location" framing is OVERSTATED: nothing on chain proves a base station is where it claims to be. The claim of any ON CHAIN proof of location is FALSE. Trust rests entirely on GEODNETs private backend and the SNR / neighbor-distance heuristic it applies.

## Claim 2: Operators "mine" GEOD, which is minted and distributed to each miner

CLAIM: "Mined tokens will be unlocked and distributed to each miner daily," on a halving schedule (96 to 48 to 24 GEOD/day for a triple band station across 2022 to 2025).

REALITY: No minting occurs. The full 1B supply is pre minted (totalSupply == cap == 1e27) and no address holds MINTER_ROLE, so on chain issuance is impossible. "Mining" is a daily payout from a pre funded wallet. The docs confirm: "GEOD tokens are automatically distributed on a daily basis at UTC time 5:30 am / PST 9:30 pm" from "Mining distribution wallet: 0x8FB9dd00B9a3D893dA96d444817d0b77330d5478." On chain, that wallet returns `0x` for eth_getCode, meaning it is an externally owned account, not a smart contract, and it has an outgoing transaction count (nonce) of 61,990 (`0xf226`), with a current working balance of 381,733.75 GEOD (about 0.038 percent of supply, i.e. a hot wallet topped up for payouts). So a backend controlled private key signs the distributions.

EVIDENCE: on chain totalSupply and cap both `0x033b2e3c9fd0803ce8000000`; getRoleMemberCount(MINTER_ROLE) = 0; eth_getCode(`0x8FB9...5478`) = `0x`; nonce = `0xf226` (61,990); balanceOf(`0x8FB9...5478`) = `0x50d5d3ec0af3afd43d04` (381,733.75 GEOD). docs.geodnet.com/geod-token/tokenomics.

IMPACT: The on chain emission narrative is FALSE. The backend distribution IS real and CONFIRMED, and the halving is a policy applied by the backend, not enforced by a contract. Positive nuance: because there is no minter, the backend cannot inflate supply beyond the fixed 1B; it can only pay out what the treasury holds. The centralization risk is custodial and operational (one EOA key, discretionary daily payouts), not inflationary.

## Claim 3: Miners register and their data is validated by the network

CLAIM: Operators register a base station on the GEODNET console with their wallet address and are rewarded for valid data.

REALITY: Registration is an off chain console account keyed to a wallet address (a database record), and validation is the backend algorithm from Claim 1. None of this is on chain and none of the registration or validation code is public. The RTK service repos in the org (GEODNET_RTK_SERVICE, rtk, rtcm, rtcm_qc, GEODNET_QC, rtklog) cover the NTRIP/RTCM data plane and quality control utilities, not miner accounting or reward issuance.

EVIDENCE: docs.geodnet.com/geod-mining/the-geod-mining-basics ("Register on GEODNET console with wallet address"); github.com/geodnet/GEODNET_RTK_SERVICE README ("GEODNET provides the RTK service globally"), which "contains no reward calculation, miner registration, or token distribution logic."

IMPACT: CONFIRMED that registration and validation exist, but they are off chain and closed. A miner cannot independently verify on chain why a given payout was granted or withheld.

## Claim 4: Fixed, capped 1 billion GEOD tokenomics

CLAIM: "The total supply of GEOD token is 1 billion," allocated across mining, ecosystem, team, investor, vendor/marketing and public sale, with rewards halving annually on June 30.

REALITY: CONFIRMED on chain. Supply is exactly 1e27 and equals the hard cap; no further minting is possible. The six allocation buckets each map to a Polygon wallet in the docs, but exact percentage splits are not published in the documentation reviewed (a minor transparency gap). The distribution wallet activity corroborates the daily payout model.

EVIDENCE: totalSupply == cap == `0x033b2e3c9fd0803ce8000000`; Sourcify v2 verified match; docs.geodnet.com/geod-token/tokenomics.

IMPACT: Positive. The scarce, capped, non inflatable supply is real and enforced by code, not merely promised.

## Claim 5: Decentralized governance (DePIN)

CLAIM: GIPs are "the fundamental mechanism for implementing changes within the GEODNET Network."

REALITY: Governance is off chain. GIPs are GitHub documents that move Draft to In Discussion to Voting Open to Approved to Deployed, with discussion in a Discord governance channel. There is no on chain voting contract and no evidence GEOD is used as a governance token to bind outcomes. Reward metric changes (for example GIP6) are decided by this process and then applied by the team in the closed backend.

EVIDENCE: github.com/geodnet/GIP (index and status workflow); no governance/voting contract observed on chain.

IMPACT: OVERSTATED. Governance framing implies decentralized control; in practice parameter changes are team executed off chain.

## Claim 6: Real world scale / "worlds largest" navigation network

CLAIM: Marketing describes GEODNET as a very large blockchain powered navigation network, with the docs stating a long term goal to "fully cover the land surface of the Earth with 100,000 evenly placed Base Stations," "approximately twenty times larger than any existing CORS network."

REALITY: UNVERIFIED in this read only pass. The docs give only the aspirational 100,000 target and no current station count. The geodnet.com homepage advertises live counters (Miners, Countries, RTK Usage GB, Annual Recurring Revenue), but these are JavaScript rendered and returned empty (0) to a static fetch, so no specific figure could be independently captured here. What IS independently observable is sustained, real distribution activity on chain: the distribution EOA has signed 61,990 transactions and continues daily payouts, which corroborates an operating network with real participants even though it does not pin down a headcount.

EVIDENCE: docs.geodnet.com (100,000 target); geodnet.com homepage counters not server rendered; on chain nonce 61,990 on `0x8FB9...5478`.

IMPACT: The existence of an active, funded, ongoing reward operation is confirmed on chain; the specific size superlatives are neither confirmed nor refuted here and should not be credited without a live console read.

## Positive Findings

1. The token is a Sourcify verified, standard OpenZeppelin ERC20 with a hard cap already reached and every privileged role (admin, minter, pauser) holding ZERO members. No mint, no pause, no admin, no proxy, no upgrade path. This is a genuinely ossified, low risk token contract.
2. No honeypot patterns: standard transfer/approve/permit surface, no blacklist or trading tax logic implied by the verified standard composition.
3. Supply cannot be inflated. Even though distribution is centralized, the backend can only ever pay out from a fixed 1B pool; it cannot print new GEOD.
4. Real underlying utility: GEODNET operates a live global RTK/NTRIP correction service (multiple regional casters) delivering centimeter grade positioning, and the reward metrics are grounded in real GNSS signal quality, not arbitrary emissions. Peripheral tooling (RTCM parsing, quality control, coordinate systems) is genuinely open source.
5. Distribution is auditable at the ledger level: payouts are public Polygon transfers from a single, documented wallet, so token flows can be traced even though the reasoning behind them is private.

## Conclusion

GEODNET is a legitimate DePIN with a real product (a working RTK correction network) and one of the cleaner token contracts in the sector: a verified, capped, fully minted, role renounced ERC20 that cannot be inflated, paused, or upgraded. That is the strong part, and it is fully CONFIRMED on chain.

The weak part is the gap between the decentralized, "proof of location," "mine your rewards" marketing and what the code actually enforces. On chain, the blockchain is only a ledger and a payment rail. The decisions that matter (whether a stations data is valid, how much each miner earns, when to change the rules) are made by a closed GEODNET backend and executed as discretionary daily transfers from a single externally owned wallet (`0x8FB9dd00B9a3D893dA96d444817d0b77330d5478`, 61,990 outgoing txs). There is no on chain minting, no on chain proof of location, no on chain validation, and no on chain governance. The core reward engine, validation logic, and base station firmware are closed source and therefore unverifiable; per audit policy these unseen claims are not credited.

Net: the on chain emission claim is FALSE, the on chain proof of location claim is FALSE, and the decentralization, mining, and governance framing are OVERSTATED, while the token safety, capped supply, backend distribution, and real RTK utility are CONFIRMED. The honest one line description is a centrally operated, closed source RTK data service that pays a fixed, non inflatable token from a treasury wallet. The custody and centralization risks are operational (one distribution key, trust in a private backend), not token-contract exploit risks.

**Score: 64/100, MEDIUM RISK. Verdict: PASSED (with material centralization and transparency caveats).**

Rationale for the score: strong, ossified, verified token and real utility keep this well clear of scam territory and above the 51 pass line. The deductions reflect a closed source core reward and validation engine, fully off chain and discretionary reward issuance from a single EOA, off chain governance, and marketing that presents an off chain trust model as on chain decentralization and "proof of location."
