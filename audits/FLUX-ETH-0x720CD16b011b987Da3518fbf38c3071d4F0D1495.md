## Executive Summary

Flux (FLUX) is a real, long running decentralized cloud infrastructure network with a genuine node fleet, transparent metrics, and no rug indicators. It is not a scam. The MEDIUM rating reflects a reward subsidized, inflationary, multi representation reality:

1. **The token is a multi chain 1 to 1 representation set with 8 decimals:** MEFAI confirms the Ethereum representation at 8 decimals; one FLUX exists at a time on the native Flux chain or as a bridged representation, so per chain balances are not additive.
2. **Issuance did not stop with the end of mining.** In late 2025 Flux ended traditional proof of work mining and moved to a node based model, and the long term supply cap was raised from 440 million to 560 million, so the network remains inflationary via node emissions.
3. **The node fleet is real but reward subsidized.** Thousands of collateral gated nodes run the network, but node economics are driven by emissions rather than paying compute demand.
4. **Some public trackers still show the old 440 million cap,** a live data mismatch, and the token is down heavily from its 2022 peak.

The network, node fleet and transparency are real; the caution is a reward subsidized economy, an inflationary and recently raised cap, multi representation supply confusion and a deep drawdown.

## 3. Claim vs Reality: "Decentralized Cloud Infrastructure"

> Site: a decentralized Web3 cloud, a fleet of nodes running a container based operating system for applications, GPU compute and an AI push.

**Reality: real infrastructure, reward subsidized usage.** Flux runs a real, years long distributed node fleet with a genuine container based operating system and real deployments, and node onboarding is permissionless given a collateral stake, which distinguishes it from typical projects. But the node economy is sustained mainly by block reward emissions rather than paying compute customers: per node rewards are small and often do not cover hosting costs, so the network is populated by emissions rather than demonstrated external demand. The late 2025 move to a node based model is designed to tie rewards to useful work, a step in the right direction, but it does not by itself prove real paid demand, and the GPU and AI push is nascent.

---

## 4. Claim vs Reality: Supply, Economics and Value

- **Inflationary, with a raised cap:** the end of mining did not end issuance; block rewards now flow to nodes, and the long term cap was raised from 440 million to 560 million, so future dilution is higher than the old model implied.
- **Reward subsidized economy:** node participation is driven by emissions rather than paying demand, so sustainability depends on the token price and on real compute monetization.
- **Multi representation confusion:** FLUX spans many chains as 1 to 1 representations that are not additive, and some public trackers still display the old 440 million cap, a live data mismatch.
- **Value:** the token is down roughly 98 to 99 percent from its 2022 peak, a micro capitalization with thin liquidity.

## 8. Conclusion

Flux (FLUX) is a real, long running decentralized cloud infrastructure network with a genuine collateral gated node fleet, transparent public metrics and no rug indicators, which keeps it in the MEDIUM band at 60/100. It is held back because node economics are emission subsidized rather than revenue driven, because issuance continues via node emissions with the long term cap raised from 440 million to 560 million, because the multi representation supply and a stale headline cap on some trackers create confusion, and because the token is down roughly 98 to 99 percent from its 2022 peak. The network, node fleet and transparency are real; the caution is the reward subsidized economy, the inflationary and recently raised cap, the supply confusion and the drawdown.

---

## 9. Recommendations

**For the Flux team:**
- Report real paid compute and application revenue separately from emission driven node rewards.
- Ensure public trackers reflect the current 560 million cap, and clearly document the multi representation, non additive supply.
- Continue tying node rewards to demonstrable useful work.

**For users:**
- Understand node rewards are emission subsidized and the cap was raised to 560 million, and that per chain balances are 1 to 1 representations, not additive.
- Value the real network and node fleet on their merits, and model the dilution and the drawdown.
