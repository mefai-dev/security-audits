## Executive Summary

Claim vs reality audit of Streamr (DATA). A long running decentralized real time data DePIN with an immutable, non pausable, fee free Ethereum token that supports permit and transfer and call, but whose supply is mintable with no hard cap under an active team controlled admin role, so the widely quoted maximum is a market convention rather than a coded limit.

Streamr DATA is the token of a long running decentralized real time data network in the DePIN category, and its canonical DATAv2 contract on Ethereum was confirmed directly by RPC as Streamr and DATA with eighteen decimals and a live total supply of 1,337,523,352 tokens. The contract is a standard, immutable OpenZeppelin style ERC20 with ERC677 and permit support, so transfers carry no fee, there is no pause switch, and there is no proxy that could swap the logic. The one material caveat for due diligence is supply, since the token is mintable with no hardcoded cap under an active Streamr controlled admin role.

Reading the contract shows the owner call reverting while the default admin role resolves, confirming access control rather than simple ownership, and both proxy storage slots are empty, confirming a direct non proxy deployment. The paused call reverts, so there is no pause module, and the token exposes permit via a valid domain separator, consistent with the published source. Minting is possible through the minter role with the admin able to add or remove minters and no supply ceiling enforced in code, which is the primary reason this token lands in the medium tier despite otherwise clean, transparent, and battle tested mechanics.

## 3. Claim versus Reality

- "A DePIN data token" / Reality: the clean, immutable, fee free mechanics match the public docs exactly, and the project is candid that supply is not fixed. The two billion maximum seen on trackers is a market convention, not a coded cap, so the token is inflation capable by governance.

Streamr openly documents DATAv2 as role based mintable, non upgradeable, non pausable, and fee free, and each of those statements was verified against the live contract with no contradiction. The project does not claim a fixed hard cap in the contract, which matches the on chain reality that any two billion max supply number seen on market trackers is a convention rather than a coded limit. Reported circulating and total supply line up with the Ethereum on chain figure, so the public numbers are internally consistent.
