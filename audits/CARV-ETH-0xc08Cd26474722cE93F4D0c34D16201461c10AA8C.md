## Executive Summary

CARV is a real and correctly identified token. Live public RPC calls on Ethereum confirm name CARV, symbol CARV, 18 decimals, and a standard ERC20 that is actually a LayerZero omnichain fungible token deployed at the same address on Ethereum, Base, BNB Chain and Arbitrum One. The global maximum is one billion tokens and this is effectively fixed because the bytecode exposes no public mint function; new units appear on a chain only when an equal amount is burned on another chain during bridging. On Ethereum the contract holds about 262 million tokens right now, the three main EVM chains together hold roughly 993 million, and the owner key is a Gnosis Safe multisig rather than a plain wallet. The contract is not a proxy, is not pausable, and charges no transfer fee, so the main residual risk is the standard LayerZero owner power to configure trusted peers. Marketing claims about a modular data layer, the D.A.T.A. framework and verifier nodes describe offchain and separate onchain systems, not properties of this simple token contract.

The starting address is correct and the token is exactly what it claims to be at the contract level. It is a LayerZero omnichain fungible token with a fixed global cap of one billion, spread across Ethereum, Base, BNB Chain, Arbitrum One and Solana at a shared EVM address. There is no arbitrary mint, no proxy, no pause switch and no transfer fee, and the Ethereum owner is a multisig. The only real centralization vector is the routine LayerZero owner ability to set trusted peers, which every OFT shares. On the numbers and the code this is a clean, standard token deployment.

## 2. Onchain Security Assessment (MEFAI analysis)

- Global maximum one billion CARV, effectively fixed; Ethereum totalSupply about 262,382,849, Base about 557,550,269, Arbitrum about 172,755,323, summing to about 992.7 million across three EVM chains with the remainder on BNB Chain and Solana. Per chain supply floats with bridging.
- Owner on Ethereum is 0xb73123882bcbf3399a115203ddb1d880f20214a9, and its onchain code matches a Gnosis Safe multisig proxy. Arbitrum owner is a different key 0xdea3309572c85e47aecd2deb97e9ef102ffb786e, consistent with per chain LayerZero delegates.
- No public mint function in the bytecode (mint selectors 0x40c10f19 and 0xa0712d68 absent). Minting occurs only internally on receipt of a valid cross chain message from a trusted peer. setPeer and enforcedOptions selectors present, confirming a LayerZero OFT.
- Not upgradeable: both EIP1967 implementation and admin storage slots are zero, so no proxy. Not pausable: paused() reverts. No fee on transfer and standard 18 decimals. Owner can configure LayerZero peers and delegate, the sole meaningful privilege.

## 3. Claim versus Reality

- "The largest modular data layer for Gaming and AI, over 8 million CARV IDs and 60,000 plus verifier nodes" / Reality: an offchain adoption and infrastructure claim; not something the token contract can prove. The token itself is a plain omnichain OFT and carries none of this logic.
- "D.A.T.A. framework (Data Authentication, Trust and Attestation)" / Reality: a software plugin for web3 agent frameworks that feeds AI agents onchain and offchain data. It lives in CARV product code and the CARV SVM chain, not in this ERC20.
- "Verifier nodes validate ZK proofs and TEE attestations to secure the network" / Reality: verifier participation is gated by separate NFT license contracts and the CARV SVM chain, with CARV used as gas and staked to veCARV. The verifier system is real but distinct from this token contract.
- "CARV token utility: gas on CARV SVM, governance via veCARV at one to one, liquidity pairing" / Reality: consistent with a standard transferable ERC20 OFT; veCARV staking and governance are handled by external contracts.

The public site now leads with the tagline Powering the Rise of Sovereign AI Beings, while the documentation and third party research describe CARV as the largest modular data layer for gaming and AI. The headline product pieces are the D.A.T.A. framework for feeding verified data to AI agents, a network of community verifier nodes, and a custom CARV SVM chain based on the Solana Virtual Machine. These are ambitious platform claims about offchain services and a separate chain rather than features of the token itself. They are consistent with an operating project that concluded its token generation event in October 2024, but they cannot be confirmed from the ERC20 contract and should be treated as product marketing.

## 4. Website and Frontend Integrity

VERDICT: CLEAN | CONFIDENCE: high
The carv.io homepage is a standard Vite built React single page app that loads only first party asset chunks plus Google Fonts and a jsDelivr bundle pinned to CARV's own GitHub repo (carv protocol/cdn@1.0.3), with no eval, atob, base64 obfuscation, or untrusted remote drainer hosts. The only EVM contract address embedded in the code config is the correct official OFT token 0xc08Cd26474722cE93F4D0c34D16201461c10AA8C, used for the mainnet oft_arb_contract and oft_bsc_contract entries, while the remaining addresses are CARV's own bridge contracts and testnet or UAT variants gated behind a mainnet flag, so no lookalike or substituted address was found. Wallet connect is present and multichain (RainbowKit and wagmi for EVM plus Solana adapters, WalletConnect, and a Binance connector), and the sole write transaction observed is a bounded ERC20 approve whose spender is CARV's own bridge contract for the exact bridging amount after an allowance check, with no unlimited MaxUint256 approval, no Permit2 or signTypedData harvesting, and no setApprovalForAll, so it is not a drainer. Metrics and data come from live first party APIs (protocol.carv.io, public.carv.io, interface.carv.io) alongside genuine chain RPCs and the LayerZero API rather than hardcoded fakes. No audit badge or audit claim appears on the reviewed surface, so there is nothing unbacked to flag.
