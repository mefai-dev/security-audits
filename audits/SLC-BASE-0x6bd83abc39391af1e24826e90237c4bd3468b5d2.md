Every core value was read live from public Base RPC endpoints, with name, symbol, decimals, total supply, and owner cross checked on two providers. The contract is a LayerZero OFT, so on Base it mints or burns SLC only when tokens bridge in or out, and the Base total supply of about 5.68 billion is a slice of the 100 billion multichain maximum. There is no EIP 1967 proxy and paused() reverts, so the code is neither upgradeable nor pausable, and it carries no fee on transfer. The one material weakness is that owner() resolves to an externally owned account with no bytecode, meaning a single key controls the peers and delegate that define cross chain issuance. For a public directory this warrants a FLAG for admin key centralization, not a rejection, given the otherwise clean and verified contract.

## 2. Onchain Security Assessment (MEFAI analysis)

- Base totalSupply verified live via eth_call 0x18160ddd equals 5,682,879,234.34 SLC at 18 decimals; project wide max supply is 100 billion SLC per docs and CoinGecko; the Base contract exposes no cap() or maxSupply() (both revert), so there is no onchain hard cap.
- owner() equals 0x82ae4f07a69fd588625ef7c48c9b4ed9aae73e3d; eth_getCode on that address returns 0x on two independent Base RPCs, so the admin is a single externally owned account, not a multisig contract.
- Mint and emission: the contract is a LayerZero OFT (oftVersion responds; token() returns itself), there is no public mint function, and SLC is minted or burned on Base only when bridged; the owner governs the peers and delegate, i.e. the cross chain configuration.
- Not upgradeable: EIP 1967 implementation and admin storage slots are both zero, so no proxy; paused() reverts, so not pausable; standard OZ ERC20 base with no fee on transfer; decimals equals 18.

## 3. Claim versus Reality

- "Noise pollution DePIN" / Reality: corroborated by the whitepaper and third party explainers; the Silencio mobile app lets users measure ambient noise and contribute data, though the current homepage reframes the network as voice and audio data for AI and robotics.
- "Mobile app" / Reality: real, a live Silencio app spanning 180+ countries with a reported user base above 1 million.
- "Earn SLC" / Reality: the whitepaper confirms users earn SLC proportional to usage and contributions, yet the current homepage text mentions payment in stablecoin and does not name SLC, a messaging inconsistency.
- Chain claim / Reality: the presumed Polygon chain is incorrect; verified reality is Base (LayerZero OFT), with the token native on peaq and also present on Ethereum, and no Polygon contract found.

The whitepaper and independent explainers describe Silencio as a decentralized noise pollution mapping network where a mobile app turns phones into sound sensors and rewards contributors with SLC. That product is real and widely cited, with figures above 1 million users across 180+ countries. However the live homepage now frames the same effort as capturing voice and audio data for AI and robotics, and it states contributors are paid in stablecoin without naming SLC. This drift between the earn SLC narrative in the docs and the stablecoin wording on the homepage is worth flagging, even though it does not by itself indicate fraud. The token remains the incentive layer described throughout the whitepaper and exchange listings.

## 4. Website and Frontend Integrity

VERDICT: CLEAN | CONFIDENCE: high
The Silencio homepage is a static Framer marketing site (framerusercontent.com plus the events.framer.com analytics script) and contains no wallet connect, no window.ethereum usage, and no approve, permit, or transfer calls, so there is no drainer surface at all. No 0x address of any kind appears in the HTML or the main JS bundle, which means the official Base SLC contract is not published here and there is no wrong chain or lookalike address such as a Polygon variant to worry about. No obfuscation was found, with zero eval, atob, base64, or fromCharCode, and every script and outbound link points to reputable hosts (Framer CDN, huggingface, github, x.com, linkedin, dune.com, whitepaper.silencio.network, ai.silencio.store). The headline metrics such as 2.5M contributors, 180 plus countries, 500K plus hours, and the claim that the community round was 86 times oversubscribed are hardcoded text rather than live API values. The only Audit reference is the marketing line Auditable end to end by design, not a security audit badge, so nothing unbacked is claimed.
