## Why This Report Exists

Silencio markets itself as a decentralized physical infrastructure network (DePIN) whose users "earn" SLC by measuring noise, with the pitch that participation, rewards and data provenance are trustless and verifiable on chain. That is a strong claim: it implies the reward mechanism is governed by public code that anyone can audit, and that the network cannot quietly inflate contributions. A prior review flagged that the Base token owner is a single EOA controlling LayerZero peers. This report independently confirms the live token, its owner and peers on chain, reads whatever actual public source exists, and tests each flagship claim against code and on chain facts. Where the app and backend are closed, they are reported as closed and not credited.

## Method

Direct `eth_call` for name, symbol, decimals, totalSupply, owner, endpoint, token, oftVersion, sharedDecimals, approvalRequired, and `peers(uint32)` on the OFT. `eth_getCode` and `eth_getTransactionCount` to distinguish EOA from contract owners. Selectors are standard ERC20, Ownable, and LayerZero OApp getters.

- Claims are labeled CONFIRMED IN CODE / OVERSTATED / FALSE with a file, an on chain fact, or a quoted whitepaper line.

## The Foundation: what SLC actually is on chain

SLC is a fixed supply ERC20 native to peaq (`0x5c3126...886b`, totalSupply about 98.39 billion of a 100 billion cap) that is made omnichain via LayerZero V2. On peaq a lockbox OFT Adapter (`0x7fa16ced...6d1e`, `approvalRequired()` true, `token()` points at the native ERC20) locks the native token; on Base a mint and burn OFT (`0x6bd83abc...b5d2`, `token()` returns self, `approvalRequired()` false) mints against bridged supply. An Ethereum deployment sits at the same deterministic address as the peaq adapter and is wired as the Base peer for eid 30101. This is a legitimate, standard bridging design. It is important to state plainly what these contracts are: three roughly 11 to 12.5 kilobyte LayerZero token contracts. They contain ERC20 transfer, LayerZero send and receive, and Ownable administration. They do not contain, and cannot enforce, any of Silencio's product logic: no noise measurement, no data validation, no reward computation, no staking distribution. Everything that makes Silencio "Silencio" lives off chain.

## Claim 1: Noise measurement and rewards are on chain and verifiable

**CLAIM.** The marketing thesis, echoed across listings, is that Silencio is a DePIN where "users earn $SLC tokens by measuring and uploading noise levels" and where contributions cannot be "quietly inflated" because they are recorded and published on chain. The on chain proof page states that "tokens burned, the value staked, are recorded on chain and published openly" and that "participation cannot be quietly inflated."

**REALITY: OVERSTATED.** The reward and measurement pipeline is a centralized web service. The whitepaper tech stack page describes the backend as AWS (EKS Kubernetes, Application Load Balancer, CloudFront, RDS, S3, ElastiCache Redis for "leaderboards"), Node.js microservices, PostgreSQL, and Python for ML. Measurements come from smartphone microphones. Data "passes through layered validation: automated screening for technical quality, human peer review by other contributors, and expert checks on sampled data." There is no cryptographic attestation, no hardware root of trust, and no anti spoofing described. Rewards are in app "Noise Coins," an off chain points balance the backend computes and only later converts into on chain SLC. What is actually written to chain (peaq) is consent metadata, not the measurements themselves: "Each consent action is immutedly recorded on chain, specifying the type of data authorized, the device ID, and the time of contribution." Consent provenance on chain is real and mildly novel, but it is not proof that any given decibel reading, or the reward derived from it, is authentic or correctly calculated. A centralized operator that computes points in PostgreSQL and then mints SLC is precisely the trust assumption a DePIN is supposed to remove.

**EVIDENCE.**
- whitepaper technical-overview/tech-stack-+-infrastructure: "Silencio is built on a highly secure and scalable infrastructure using Amazon Web Services (AWS)"; "backend micro-services infrastructure is powered by Node.js"; data in "PostgreSQL."
- whitepaper how-we-source-data: "Contributions pass through layered validation: automated screening for technical quality, human peer review by other contributors, and expert checks on sampled data." No cryptographic proof or attestation mentioned.
- whitepaper on chain-consent: consent action records "the type of data authorized, the device ID, and the time of contribution." Measurement values are absent.
- Search corroborated tokenomics: users earn in app "Noise Coins" that "serve as an off chain rewards points system that can later be converted to on chain $SLC tokens."
- On chain: neither `0x6bd83abc...b5d2` (Base) nor `0x5c3126...886b` (peaq) nor `0x7fa16ced...6d1e` (adapter) exposes any reward, scoring or measurement function; they are OFT, OFT Adapter and plain ERC20 respectively.

**IMPACT.** The core DePIN value proposition, trustless and verifiable rewards for physical data, is not what the code does. Users must trust a private AWS backend for both the measurement and the payout. Marketing that implies otherwise is materially overstated.

## Claim 2: An on chain program governs SLC rewards and staking

**CLAIM.** The whitepaper staking page describes an "On Chain Staking (Smart Contract)" in which participants "lock their tokens into the network for a certain period in order to support the ecosystem and, in return, potentially earn rewards," directing users to https://staking.silencio.network and "peaq or the specified chain for staking."

**REALITY: FALSE as stated, OVERSTATED overall.** No staking contract address is disclosed anywhere in the whitepaper, and none of the three verified token contracts contains staking or reward distribution logic. SLC on Base is a plain mint and burn OFT; SLC on peaq is a plain ERC20 behind a plain OFT Adapter. The other, more prominent "staking" the whitepaper describes is explicitly off chain: "Staking boosts your OG bonus for future raffles," with users picking 25/50/75/100 percent and 3 to 18 month durations to weight a monthly raffle, an in app gamification feature, not a smart contract. Rewards under the on chain variant are, by the whitepaper's own words, "discretionary rewards determined by the Silencio Foundation," which is the opposite of program enforced staking. Because no address is published and no staking bytecode is visible in the token contracts, the on chain staking claim is unverifiable and, at the level of "the SLC contract governs rewards or staking," false.

**EVIDENCE.**
- On chain: `oftVersion()` on Base returns the standard OFT interfaceId `0x02e49c2c`; `token()` returns self; there is no stake, unstake, claim or reward selector in a roughly 12.5 kilobyte OFT.
- whitepaper tokenomics/staking: in app staking is a raffle bonus; on chain staking pays "discretionary rewards determined by the Silencio Foundation"; "no specific contract address is provided."

**IMPACT.** SLC is a bridged utility and speculation token, not a token whose rewards are enforced by public code. The staking narrative should be read as an off chain, discretionary program.

## Claim 3: First fully on chain DePIN on peaq

**CLAIM.** Listings repeat that "Silencio is the first fully on chain DePIN on the Peaq blockchain" processing "more than 100,000 transactions daily."

**REALITY: OVERSTATED.** peaq's role is device DID, consent anchoring and token settlement, not full data settlement. The noise catalog ("hundreds of thousands of hours"), the scoring, and the rewards ledger are off chain in AWS. Any daily transaction count on peaq reflects consent or identity writes and token movements, not verifiable proof of measurements. "Fully on chain" is inconsistent with a Node.js and PostgreSQL backend that is the source of truth for both data and rewards.

**EVIDENCE.** whitepaper on chain-proof restricts on chain claims to "Burns, staking, holders, and transfers" plus consent records and device provenance; tech stack page places the data and processing in AWS. peaq native ERC20 supply verified at about 98.39 billion, consistent with a settlement token rather than a per measurement ledger.

**IMPACT.** The degree of decentralization is smaller than advertised. peaq is a settlement and identity layer bolted onto a conventional web2 data platform.

## Claim 4: A decentralized network (token and bridge control)

**CLAIM.** DePIN framing implies decentralized control of the network and its token rails.

**REALITY: OVERSTATED, with a High severity centralization fact.** Both LayerZero endpoints are owned by single externally owned accounts. On Base, `owner()` is `0x82ae4f07a69fd588625ef7c48c9b4ed9aae73e3d` (code length 0, an EOA). On peaq, the OFT Adapter `owner()` is `0xe123ffaa9d76664e2df2531534be5c20dac7cd11` (code length 0, an EOA). These owners can call `setPeer`, `setDelegate` and endpoint configuration, which means whoever holds either private key defines which remote contracts are trusted and can, through LayerZero mint and unlock semantics, influence cross chain supply. There is no multisig and no timelock in front of either. This confirms and extends the prior review: the single EOA controlling peers is present on both the Base OFT and the peaq adapter.

**EVIDENCE.**
- Base `owner()` returns `...82ae4f07a69fd588625ef7c48c9b4ed9aae73e3d`; `eth_getCode` returns `0x` (EOA); Base nonce 30.
- peaq adapter `owner()` returns `...e123ffaa9d76664e2df2531534be5c20dac7cd11`; `eth_getCode` returns `0x` (EOA); peaq nonce 30.
- Base `peers(30101)` and `peers(30302)` both return `0x7fa16ced...6d1e`, set by that owner.

**IMPACT.** The token's cross chain trust graph is a single key on each chain. This is a real key management and single point of failure risk, common to early OFT deployments but incompatible with strong decentralization claims.

## Claim 5: The app is real and has a large user base

**CLAIM.** "Operations in over 180 countries," "460,000 sensors" (earlier peaq marketing said 35,000), "millions of contributors."

**REALITY: app CONFIRMED, scale OVERSTATED / unverifiable.** The consumer app is real and actively maintained: an Apple App Store developer page for "Silencio Network LLC" and an Android build at version 4.6.6 updated 2026-07-09, described as a Web3 app to "measure noise levels earn Noise Coins contribute to global sound map." So the product exists and functions. The user base and sensor figures, however, are self reported by the same off chain backend that computes rewards, and there is no on chain artifact that independently corroborates 460,000 devices or millions of contributors, because measurements are off chain. Public third party mirrors are modest (one Android mirror shows about 2,127 downloads and 6 reviews, though the primary Google Play channel is larger and not read here). The honest statement is that the app is genuine while its headline scale cannot be verified from public code or chain data.

**EVIDENCE.** App Store developer "Silencio Network LLC"; Android v4.6.6 (2026-07-09), publisher "QkInnovations"; "Noise Coins" wording confirms the off chain points model. No on chain device registry counted here corroborates the marketing totals.

**IMPACT.** Treat scale metrics as vendor reported. The app itself is not vaporware.

## Claim 6: Real traction and fundraising

**CLAIM.** "Silencio Network Breaks Records: $112 Million in Allocation Requests, Surpassing Target by 220x." Listed on KuCoin, Gate, MEXC, BitMart, BingX.

**REALITY: OVERSTATED.** Allocation requests are demand indications, not capital, and the disclosed ICO actually raised about $1.3 million in December 2024. Verifiable market reality now is a microcap: market cap about $1.57 million, fully diluted valuation about $5.98 million, 24h volume about $106K, circulating about 25.9 billion of 100 billion, price about 90 percent below the February 2025 all time high. The exchange listings are real, but the "$112 million, 220x" framing is a fundraising headline that is an order of magnitude or more above the token's actual valuation and liquidity.

**EVIDENCE.** CoinGecko market data verified this session; on chain circulating and total supply consistent (Base bridged about 5.81 billion, peaq about 98.39 billion, max 100 billion).

**IMPACT.** Prospective participants should weight the audited market data over the promotional oversubscription number.

## Positive Findings

- The token is a canonical LayerZero V2 OFT and OFT Adapter, a mature and widely reviewed standard, not a custom bridge. Base OFT decimals 18, sharedDecimals 6, standard oftVersion. Supply is fixed on peaq and matches the disclosed 100 billion cap; no hidden inflation or discretionary mint function was found in the token contracts.
- A real, actively updated consumer app exists on both iOS and Android, with a coherent product (noise mapping, later extended to voice data). This is a genuine operating company, not a shell.
- On chain consent anchoring on peaq (data type, device ID, timestamp) is a legitimate, somewhat differentiated provenance feature, useful for the data licensing pitch even though it does not validate measurement content.
- The whitepaper is, in places, candid: it states plainly that in app staking is off chain raffle mechanics and that Noise Coins are points, and it exposes the buy back and burn (75 percent of data revenue, 50 percent burned) with burns inspectable on peaq subscan and Dune. Partial transparency is better than none.

## Conclusion

Silencio is a real product with a real, if modest, token economy, wrapped in DePIN marketing that overstates how much of the network is actually on chain and how decentralized it is. The verifiable facts: SLC is native on peaq (`0x5c3126...886b`, about 98.39 billion of a 100 billion cap) and bridged to Base as a standard LayerZero mint and burn OFT (`0x6bd83abc...b5d2`, about 5.81 billion bridged), with both bridge endpoints controlled by single externally owned accounts (`0x82ae4f07...73e3d` on Base, `0xe123ffaa...cd11` on peaq). The measurement, validation and reward engine that the pitch calls trustless and on chain is in fact a centralized AWS backend that computes off chain "Noise Coins" and then mints or unlocks SLC. There is no verifiable on chain reward or staking program; the token contracts are plain OFT rails. The core code (backend, ML, reward engine, any staking contract) is closed or unverifiable, so those claims are not credited; only three thin client side peaq SDK wrappers are open. Traction is a genuine but microcap market (about $1.57 million cap, about $106K daily volume) that is far below the promotional fundraising headlines.

This is not a scam or a rug: the app, the token, the standard bridge and the small market are all real. It is a project whose decentralization and verifiability claims are materially overstated and whose critical infrastructure is centralized and closed. Score 48 of 100, MEDIUM risk, Flagged, weighted down chiefly by single EOA bridge control on both chains, where the same unprotected key is both OApp owner and endpoint delegate, so one key can set a hostile peer and a threshold one DVN and forge an inbound message to mint unlimited SLC or unlock the billions of SLC locked on the peaq adapter, plus off chain rewards, a false on chain staking claim, closed core code and inflated traction framing, and kept off the flagged floor by a real product, a standard clean fixed supply token, and partial disclosure.
