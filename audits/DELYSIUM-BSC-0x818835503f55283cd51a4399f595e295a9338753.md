## Summary

A real, funded, exchange listed project whose product exists, but its big tech partnership marketing is materially misleading, its autonomous AI agent claim is overstated and unbacked by public code, and its BNB Chain token is a legacy Multichain style bridge token with a mint capable, non renounced admin key held by a single address associated with the now defunct Multichain bridge system.

## Website claim versus reality
- "Together with" logo strip showing Google, Microsoft, NVIDIA, Polygon, BNB Chain, Immutable / Misleading framing. Google is a Cloud startup program participant, not an investor. The Microsoft "partnership" release was issued by Delysium and describes Microsoft only as an Azure cloud provider. NVIDIA is the free Inception accelerator (40,000 plus members). Polygon is a build chain choice and possible investor, the closest to real. The logos carry no explanatory text.
- "Incubated by Y Combinator" / UNVERIFIED. Delysium was not confirmed in the YC directory. The related company rct AI is YC, not Delysium.
- "Lucy, an AI Powered Web3 Operating System" as an autonomous agent / Overstated. Lucy's own site describes a user directed copilot powered by MCP, consistent with a chat front end orchestrating hosted LLMs with a wallet attached. No onchain evidence of agents transacting autonomously. GitHub org has zero public repos.
- Site metrics "0M+ wallets", "0M+ transactions" / UNVERIFIED. The live counters render as literal placeholders, so no real scale figure could be read.

### Onchain contract audit
- The BSC AGI token is an Anyswap and Multichain "anyToken": mpc(), vault(), underlying(), the token side Swapin method and a mint() selector plus getAllMinters (four external minter contracts) are all present. Ownership is NOT renounced, and owner equals vault equals the mpc key (a single, uncapped mint authority). The mpc key is a single, non renounced address; whether it is Multichain's own canonical key or a Delysium held key could not be independently confirmed. Multichain itself ceased operations in July 2023 after its keys were compromised, so if the address is the former it sits with a defunct and previously compromised system. Either way it is a single uncapped mint authority, which is a serious unresolved custody and mint risk.
- GoPlus (chain 56): buy tax 0, sell tax 0, not a honeypot, freely sellable, but hidden_owner equals 1, is_mintable equals 1, and owner_change_balance equals 1 (the owner can alter balances), which strengthen the risk case.
- Concentration: top non LP wallet about 36.85 percent, insiders about 77 percent (Treasury 57 plus Team 20). Liquidity thin, about 49 thousand dollars.
