## Executive Summary

Delysium is a real, venture funded, exchange listed AI agent project with a live product (the "Lucy" assistant). It is not an outright honeypot or exit scam: the AGI token has 0 percent transfer tax, is freely sellable, has more than 10,000 holders, and the Ethereum native contract is a clean, standard ERC20.

The HIGH risk rating is driven by three independent problems on the BNB Smart Chain token specifically, plus two project level integrity issues:

1. **The BSC AGI token is a legacy Anyswap / Multichain "anyToken".** Its mint authority is a single, non renounced key (`owner() == vault() == mpc()`), it exposes a live `mint()` function and four external minter contracts, and it is the exact contract type whose administrative keys were part of the Multichain bridge system that ceased operations and was drained in July 2023. GoPlus independently flags the token as `is_mintable = 1`, `hidden_owner = 1`, and `owner_change_balance = 1`.
2. **Supply concentration is extreme.** The largest non liquidity wallet holds roughly 36.85 percent of BSC supply, and the published allocation places roughly 77 percent with the treasury (57 percent) and team (20 percent).
3. **On chain liquidity is thin** (roughly 49 thousand dollars in the main PancakeSwap pool), which combined with the mint capability creates real exit risk.
4. **Marketing presents commodity startup programs as strategic big tech partnerships** (Google, Microsoft, NVIDIA).
5. **The autonomous agent narrative is unbacked by any public code** (the GitHub organization has zero public repositories).

Users who buy the BSC AGI token are exposed to an uncapped, non renounced mint authority tied to a defunct bridge system. This is a token and marketing risk, not an accusation of criminal conduct.

## 3. Multichain Legacy Bridge Risk (Primary Finding)

The BSC AGI contract implements the Anyswap / Multichain "anyToken" interface. On chain probing confirmed the following selectors and values are present:

- `mpc()` `0xf75c2664` returns `0xb76e...6e0f`
- `vault()` `0xfbfa77cf` returns the same address
- `owner()` `0x8da5cb5b` returns the same address
- `underlying()` `0x6f307dc3` returns `0x0` (native mint/burn, no collateral locked)
- `getAllMinters()` returns **four external minter contracts**
- token side `Swapin(bytes32,address,uint256)` `0xec126c77`, `mint()` `0x40c10f19`, `burn()` `0x9dc29fac`, `setMinter()` `0xfca3b5aa`, `isMinter()` `0xaa271e1a` are all present

This interface combination is unique to Anyswap AnyswapV5/V6 ERC20 tokens. In this design, whoever controls the `mpc` / `vault` key can mint the token without limit.

**The context that makes this HIGH risk:** Multichain (formerly Anyswap) ceased operations in July 2023. Its CEO was detained in May 2023, and roughly 125 million dollars was drained from Multichain bridges on 7 July 2023; all of its MPC nodes reportedly ran under the CEO's personal account (Bloomberg, CoinDesk, Chainalysis, DL News). Delysium later announced (January 2025) a move to Wormhole / Portal.

**Honest limitation:** on chain we can prove `owner == vault == mpc` is a single, non renounced address. We could not independently prove whether `0xb76e...6e0f` is Multichain's canonical MPC key or a Delysium controlled key. Either way it is a single, uncapped mint authority on a contract type tied to a defunct and previously compromised bridge system, which is the material risk.

## 6. Claim vs Reality: "Big Tech Partnerships"

The delysium.com homepage shows a "Together with" logo strip featuring Google, Microsoft, NVIDIA, Polygon, BNB Chain and Immutable, with no explanatory text. Verified against primary sources:

- **Google** / Delysium's own Medium post states it joined "Google Cloud's AI and Web3 Startups Program" and received a 350,000 dollar Google Cloud credits grant. This is a startup credits program (`cloud.google.com/startup/web3`), open to many funded startups, not strategic backing or investment.
- **Microsoft** / The "partnership" is a self issued press release (GlobeNewswire, 14 November 2023, "Source: Delysium"), mirrored on Delysium's Medium. Microsoft made no statement; only a Delysium co founder is quoted; the substance is Azure cloud usage. No Microsoft newsroom announcement exists.
- **NVIDIA** / Delysium's own X account states they are "early members of the NVIDIA Inception Program", NVIDIA's free startup accelerator with 40,000 plus members (`nvidia.com/en-us/startups`).
- **Polygon** / A genuine build chain choice and possible venture investment, the closest to a real relationship.
- **"Incubated by Y Combinator"** / UNVERIFIED. Delysium was not found in the YC company directory; the related company rct AI is a confirmed YC company, but that does not transfer to Delysium.

**Reality:** these are commodity startup programs and cloud vendor relationships presented, via an unlabeled logo wall, as strategic partnerships with the world's largest technology companies.

## 7. Claim vs Reality: "Autonomous AI Agent (Lucy)"

Delysium markets "Lucy, an AI Powered Web3 Operating System" and an "Agentic Operating System for Crypto". Lucy's own site describes a user directed assistant / copilot powered by "YKILY MCP (Model Context Protocol)". MCP is a standard LLM tool calling protocol.

**Reality:** this is consistent with a chat front end orchestrating hosted large language models plus APIs with a wallet attached, not a novel autonomous on chain agent. No on chain evidence of agents transacting autonomously was found, and the specific LLM provider is undisclosed. The homepage scale counters render as literal placeholders ("0M+ wallets", "0M+ transactions"), so no user or transaction figure could be independently read.

## 12. Conclusion

Delysium is a real project with a live product, but the BNB Smart Chain AGI token carries a HIGH structural risk that the marketing does not disclose: a non renounced, uncapped mint authority on a Multichain style anyToken tied to a bridge system that collapsed in 2023, combined with heavy insider concentration and thin on chain liquidity. Separately, the project's headline "big tech partnerships" are commodity startup programs, and the autonomous agent narrative is unsupported by any public code. The clean Ethereum native token and the absence of transfer tax keep this out of the CRITICAL band, but a score of 35/100 (HIGH) reflects a token whose worst case (an uncapped mint by a single legacy key) is severe and undisclosed.

---

## 13. Recommendations

**For the Delysium team:**
- Migrate the BSC token off the Multichain anyToken contract to a standard, mint capped or renounced ERC20, and publicly disclose who controls `0xb76e...6e0f`.
- Publish the smart contract and agent code, or clearly state that the "autonomous agent" is an assisted copilot over hosted models.
- Relabel the partner logo strip with accurate descriptions (startup program, cloud vendor, accelerator member) rather than implying strategic partnerships.
- Populate the on site metrics with real, sourced figures or remove the placeholders.

**For users:**
- Treat the BSC AGI token as mint capable: your holdings can be diluted by the admin key at any time.
- Prefer the clean Ethereum native contract if exposure is desired, and size positions for thin on chain exit liquidity.
- Do not rely on the "Google / Microsoft / NVIDIA" logos as evidence of strategic backing.

## 14. Methodology

On chain facts were read directly from a BSC RPC node (`bsc-dataseed.binance.org`) via `eth_call` and `eth_getCode`, with function selectors computed locally (keccak-256), and cross checked against the GoPlus token security API (chain 56) and CoinGecko. Multichain shutdown facts were taken from Bloomberg, CoinDesk, Chainalysis and DL News. Partnership claims were verified against each partner's own program pages and Delysium's own posts. Every material finding was verified by at least two independent methods and then re run through a separate adversarial review; items that could not be confirmed are labeled UNVERIFIED.
