## Executive Summary

Virtuals Protocol is a legitimate, liquid AI agent launchpad. It is not a rug: the token, liquidity and buyback-and-burn tokenomics are real, and MEFAI verified a broad holder base. The MEDIUM rating is driven by a gap between the "autonomous, co-owned, on-chain agents" marketing and the centralized reality:

1. Agent intelligence (the model inference) runs on Virtuals-hosted, access-keyed servers, not on-chain. The bonding-curve launchpad and token are real, but the "autonomy" is delivered through a hosted service.
2. A documented March 2025 incident, in which a flagship agent's wallet was drained through a hosted dashboard, demonstrates that operations flow through centralized, operator-held access rather than a trustless agent.
3. The whitepaper's governance pillar is unfulfilled (published as "[REDACTED] ... Forthcoming"), so token "co-ownership" is economic exposure without governance or operational control.
4. On-chain exit liquidity is thin relative to market cap.

## 2. On-chain Security Assessment (MEFAI analysis)

MEFAI's on-chain reads confirmed the token identity, supply and holder breadth. VIRTUAL is a verified, widely-held ERC-20 on Base and Ethereum with roughly 1 billion aggregate supply and over a million Base holders, which is a broad, non-whale-captured token-level distribution.

**Note:** a direct read of the owner/mint-function state via the Base explorer was blocked to automated tooling at review time and is labeled UNVERIFIED; it should be confirmed manually on the contract's read/write interface. The agent-wallet key custody model is likewise not disclosed and is UNVERIFIED.

---

## 3. Claim vs Reality: "Autonomous On-chain Agents"

> Whitepaper: "a coordinated, onchain ecosystem where autonomous agents have identity, capital, jobs, markets, governance".

**Reality:** agents do have on-chain wallets and tokens (real), but their **intelligence is not on-chain**. The open source agent SDK requires a hosted API key and routes all planning and inference through Virtuals-operated servers. Transaction signing itself is done locally by the operator by default, but the decision-making and the hosted dashboard path are centralized. The word "autonomous" describes model-generated behavior running on a hosted service, not a trustless, self-custodial on-chain agent.

---

## 4. The March 2025 Agent Wallet Incident

On 18 March 2025, a flagship Virtuals agent's wallet lost **55.5 ETH (approximately 106 thousand dollars)** when an attacker accessed a hosted dashboard and queued malicious actions that drained the wallet. The team's response, switching access keys and migrating servers, confirms that agent operations and funds flow through **centralized, operator-held access**, not autonomous on-chain agency. This was a hosted-operations compromise (a prompt/dashboard path), not a token contract exploit, and it is the clearest evidence that "autonomous" overstates the architecture.

---

## 5. Claim vs Reality: "Co-ownership and Governance"

> Marketing: token holders "co-own a portion of the agent" with "governance rights".

**Reality:** in practice the agent token is a **revenue-share plus speculation instrument** (agent service fees fund buyback-and-burn of the token). The whitepaper's governance layer is published as **"[REDACTED] ... Forthcoming"**, i.e. not yet delivered. Holders control neither the agent wallet, the model, nor the servers. "Co-ownership" is economic exposure, not operational or governance control.

## 6. Liquidity Analysis

- Circulating market cap: approximately **377 million dollars**.
- Deepest on-chain pool: approximately **4.9 million dollars** (Base, VIRTUAL against WETH); total Base on-chain liquidity approximately **9.1 million dollars**.
- On-chain liquidity is therefore roughly **2.4 percent** of circulating market cap: still thin, so large on-chain exits face meaningful slippage even though the token is broadly held and CEX-traded.

## 11. Conclusion

Virtuals Protocol is a real, liquid, broadly-held AI agent launchpad, which keeps it out of the high-risk band. The MEDIUM rating (45/100) reflects that the core marketing, autonomous and co-owned on-chain agents, materially overstates a centralized reality: inference runs on hosted, access-keyed servers, a 2025 dashboard drain confirmed operator control of agent funds, governance is undelivered, and on-chain exit liquidity is thin. The token is not a scam; the caution is about believing the autonomy and co-ownership narrative.

---

## 12. Recommendations

**For the Virtuals team:**
- Clearly distinguish "hosted AI agents with on-chain wallets" from "autonomous on-chain agents", and disclose the agent-wallet custody model.
- Ship the governance layer, or stop marketing token "co-ownership" and "governance rights".
- Publish the owner/mint state transparently.

**For users:**
- Treat agents as hosted services with on-chain wallets, not trustless autonomous programs.
- "Co-ownership" is revenue exposure, not control; size positions for thin on-chain exit liquidity.
