## Summary

A legitimate, liquid AI agent launchpad, not a rug. The token, liquidity and buyback and burn tokenomics are real. The core marketing framing is misleading: agent intelligence (LLM inference) runs on Virtuals hosted, access keyed servers, and token co ownership confers economic exposure without governance or operational control. Wallet signing is operator side by default, but the hosted dashboard path is what let the aixbt agent be drained.

## Website claim versus reality
- "a coordinated, onchain ecosystem where autonomous agents have identity, capital, jobs, markets, governance" / Materially overstated. Agents have onchain wallets (real), but their intelligence is not onchain. The open source GAME SDK requires a GAME_API_KEY and routes all planning and inference through Virtuals hosted servers (transaction signing itself is done locally by the operator by default). The whitepaper governance section reads "[REDACTED] Forthcoming".
- "Luna ... now able to transact freely onchain ... autonomously" / Automation is genuine, self custody is not. On March 18, 2025 the flagship agent aixbt lost 55.5 ETH (about 106 thousand dollars) when a hacker accessed a secure dashboard and queued malicious replies that drained a wallet. The team response, switched access keys and migrated servers, confirms funds flow through centralized operator held keys.
- "co own a portion of the agent ... governance rights" / Misleading. In practice the agent token is a revenue share plus speculation instrument (service fees fund buyback and burn). Holders control neither the wallet, the model nor the servers.

### Onchain contract audit
- VIRTUAL is a verified ERC 20 on Base and Ethereum, about 1 billion aggregate supply (the Base contract itself reports about 497 million), about 1 million plus Base holders (broad distribution). LP is live on Aerodrome and Uniswap; the deepest pool (Aerodrome VIRTUAL against WETH) holds about 4.9 million dollars and total Base liquidity is about 9.1 million dollars, which is still thin (about 2.4 percent) relative to a circulating market cap near 377 million dollars.
- UNVERIFIED: direct owner and mint function read (BaseScan returned 403 to automated reads), and the agent wallet key custody model.
