## Summary

A real, VC backed AI agent platform with genuinely open source models and a Binance listing. This is not a rug. The headline decentralized AI consumer layer claim does not survive scrutiny: agent inference runs on centralized third party APIs and MyShell hosted models, with no node or validator set.

## Website claim versus reality
- "MyShell is a decentralized AI consumer layer" / Misleading. The AI is not decentralized. ShellAgent orchestrates centralized model APIs, and MyShell's own docs list powerful language models such as OpenAI GPT 4 and Anthropic's frontier model (centralized endpoints). There is no public node set and no distributed inference in any of the org's GitHub repos.
- Implied decentralized or onchain architecture / Contradicted by their own docs, which frame blockchain as a future step: once the MyShell ecosystem integrates with permissionless blockchain. Yet the product is already marketed as DeAI.
- "We've independently developed several open source AI models" / TRUE, verified. github.com/myshell-ai hosts OpenVoice (37.1k stars, MIT), MeloTTS (7.6k, MIT), JetMoE (Apache 2.0). This claim holds and deserves credit.
- Traction "5 million users, 200,000 creators, 20,000+ agents" / UNVERIFIED. Self reported figures echoed by third parties; the onchain token has only about 28,947 holders.

### Onchain contract audit
- Ethereum side: the top holder is a single externally owned account holding 54.72 percent, number 2 and number 5 are known Binance wallets, top 5 about 89 percent.
- Onchain DEX liquidity is thin: PancakeSwap v3 SHELL against WBNB about 116 thousand dollars, Uniswap v4 SHELL against USDT about 1.7 thousand dollars. Price discovery is almost entirely on centralized exchanges.
- Token contract owner is a contract (likely the LayerZero OFT controller), so mint and burn exist via bridge mechanics with owner control.
